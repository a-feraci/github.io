01 // Project overview

What is it?

I built this dashboard to turn AI engineering study into a practical build-and-document workflow. It organizes curriculum tasks, skill-priority decisions and companion projects, and saves progress locally in the browser.

02 // Implemented functionality

What I can demonstrate

  • Track coursework and companion-build tasks using an interactive checklist.
  • Calculate overall course progress and display completed items.
  • Save progress in localStorage and export/import progress between devices.
  • Categorize topics by whether to master, understand, complete or skip extra study.
